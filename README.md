# Literatura de A.A.

Biblioteca web en español publicada con GitHub Pages. Incluye un catálogo con búsqueda y filtros para libros oficiales, libros relacionados, Grapevine y folletos.

## Publicación

https://carlosalmi.github.io/literatura-aa/

## Archivos del sitio

- `index.html`: portada, búsqueda y presentación del catálogo.
- `styles.css`: diseño adaptable a móvil y escritorio.
- `catalog.js`: títulos organizados por sección.
- `section-assets.js`: relación entre títulos, tapas y PDF.
- `covers/` y `pdfs/`: recursos de la biblioteca.

El repositorio es público. Antes de distribuir cada documento, verifica que cuentes con autorización para compartirlo.
